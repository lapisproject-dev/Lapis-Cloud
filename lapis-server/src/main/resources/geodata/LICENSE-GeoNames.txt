Processing applied to the raw file before it became de-postal-centroids.csv, next to
this license file:
- Raw format (tab-separated): country_code, postal_code, place_name, admin_name1,
  admin_code1, admin_name2, admin_code2, admin_name3, admin_code3, lat, lon, accuracy.
- Filtered to Germany, deduplicated on the 5-digit postal code (first occurrence per
  postal code wins where GeoNames lists more than one place name for it).
- Reduced to 4 columns: postal_code, place_name, lat, lon (lat/lon rounded to 4
  decimal places).
- Result: 10,813 entries, all within Germany's bounding box (approx. 46-55.5 N,
  5-16 E) -- no out-of-range coordinate survived the filter.
