= Action icons and tool rows (V1.9.43)
:toc:

== Purpose

One table maps a verb to its icon, so that the same action looks the same on every screen and one picture never means two things. The icons are
Font Awesome 7, bundled by webpack through `kvision-fontawesome` (no CDN, no new dependency). The code is `ActionIcon.kt`, `ActionButton.kt` and
`ToolbarRow.kt` in the client.

== Verb to icon

[cols="2,3,3", options="header"]
|===
| `ActionIcon` | Icon | Used for
| `REFRESH` | `fa-arrows-rotate` | Aktualisieren, Neu laden, Erneut versuchen, Nachbuchen
| `EDIT` | `fa-pen` | Bearbeiten, Umbenennen
| `DELETE` | `fa-trash` | Löschen (always `OUTLINEDANGER`)
| `REMOVE` | `fa-circle-minus` | Entfernen, Zuordnung aufheben: detach, the object itself survives
| `SAVE` | `fa-floppy-disk` | Speichern (the check mark belongs to `APPROVE`)
| `CANCEL`, `CLOSE`, `CLEAR` | `fa-xmark` | Abbrechen, Schließen, Suche leeren
| `ADD` | `fa-plus` | Hinzufügen, Anlegen, "Neu ..."
| `SEARCH`, `FILTER` | `fa-magnifying-glass`, `fa-filter` | Suchen, Filtern
| `DOWNLOAD`, `UPLOAD`, `EXPORT` | `fa-download`, `fa-upload`, `fa-file-export` | Herunterladen, Hochladen, Exportieren
| `COPY`, `PRINT` | `fa-copy`, `fa-print` | Kopieren, Duplizieren, Drucken
| `VIEW` | `fa-eye` | Details anzeigen, Anzeigen, Vorschau
| `OPEN_EXTERNAL` | `fa-arrow-up-right-from-square` | opens another site or tab
| `BACK`, `NEXT` | `fa-arrow-left`, `fa-arrow-right` | Zurück, Weiter, Öffnen
| `APPROVE`, `REJECT` | `fa-circle-check`, `fa-circle-xmark` | Genehmigen, Ablehnen
| `SEND` | `fa-paper-plane` | Senden, Per Post versenden
| `REVOKE` | `fa-ban` | Widerrufen, Deaktivieren
| `LOCK`, `SETTINGS` | `fa-lock`, `fa-gear` | reserved
| `UNDO` | `fa-rotate-left` | Stornieren, Zurückziehen, Wiederherstellen, Zurücksetzen
|===

The aliases `fa-times`, `fa-edit` and `fa-refresh` are forbidden (tripwire). `ActionButtonDomTest` checks that every icon name exists in the
bundled stylesheet; without that check a wrong name renders an invisible icon and no error.

== Usage rules

* Outside tables: icon plus text. In tables: from two actions per row icon-only `btn-sm` with `title` and `aria-label`; with one action icon plus text.
* The icon is decoration (`aria-hidden`); the visible text is the accessible name and is unchanged. Labels are static `tr()` texts.
* Do not mix `btn-sm` into a tool row; the buttons of a row keep one height.
* Confirm dialogs: the confirming button takes the icon of its verb through `confirmIcon`; the cancelling button always gets `CANCEL`.

== Tool rows

`lapisToolbar()` is the one container for fields and buttons on a row (see R56 in `ui-ux-guideline.adoc`). Reason: KVision wraps each field in a
`form-group kv-mb-3` (label above, 16 px margin below), so centring left the button 8 px high and `align-items-end` left it 16 px low. The toolbar
aligns at the bottom of the controls and drops that margin. `toolbarText()` puts plain text in a control-height box.

== Deliberately without a standard icon

Domain verbs that have no standard picture keep their text only: for example "Abstimmung eröffnen", "Konsensieren eröffnen", "Wahl eröffnen",
"Stream unterbrechen", "Gebot abgeben", "Rechnung stellen", "Mandat erteilen", "Verrechnen ...", "Mehr laden", "Laden", "Prüfen", the
`Zum ...` navigation buttons and the conference control bar. Inventing a picture for each would blur the one-picture-one-verb rule.

=== Finance, V1.9.45

The finance screens use the table wherever it names the verb unambiguously: "Mandat widerrufen" and "SEPA-Lastschrift deaktivieren" take `REVOKE`,
"Posten stornieren" takes `UNDO` (as "Stornieren" of a batch did before), the "Nachbuchen" button takes `REFRESH`, "Vorschau berechnen" takes `VIEW`,
"Beleg/Notiz bearbeiten" takes `EDIT`, "Buchungszeile hinzufügen" takes `ADD`, "Kontenzuordnung speichern" and "Token speichern" take `SAVE`,
"Als neuen Entwurf duplizieren" takes `COPY` (a judgement call: duplicating is copying, hence the table row above now lists it), "Nur
fehlgeschlagene erneut versuchen" takes `REFRESH`, "Kontoauszug hochladen" takes `UPLOAD`. Where the table and a hand-written list of "domain
verbs" disagreed, the table won.

Without a standard icon, each for the reason given:

* *Booking and settling:* Buchen, Direkt buchen, Endgültig buchen, Ausgleichen ..., Jetzt ausgleichen, Verrechnen ..., Endgültig verrechnen -- the
  accounting act has no standard picture; a check mark would claim "approve".
* *Dunning:* Mahnhinweis Stufe %1 ausstellen, Stufe überspringen.
* *SEPA runs:* Ankündigen, Datei erzeugen, Als eingereicht markieren, Abrechnen, "Lauf anlegen (n Positionen, Betrag)" (the label carries server numbers
  and an amount, and `actionButton` takes a static label only), Mandat erteilen, Rücklastschrift erfassen ("erfassen" is not in the table).
* *Consent and activation:* SEPA-Lastschrift aktivieren ..., "Ich bestätige ...", Aktivieren, TAN bestätigen, Neu anmelden ....
* *Bank statement:* Diesem Beitrag zuordnen, Als Spende zuordnen, Zeile ignorieren.
* *Accounting export:* Verbindung prüfen, Bestätigen, Prüfen, Zuordnen, Übertragen, In %1 gefunden, Nicht gefunden; "Token entfernen" (the credentials
  are deleted: `REMOVE` would mean "detach", `DELETE` is the bin of an object); "Lauf abbrechen" (cancels a running job, not "close a form").
* *Loading:* "Laden" (first load is not "reload"), "Mehr laden" and "Weitere ... laden" (pagination).
* *Switches and navigation:* Hauptbuch / Kassenbuch, link buttons, filter chips, "Altersstruktur anzeigen".

The two finance rows that stay as strings in `tableActionButton("fas ...")` are domain verbs with no `ActionIcon` entry: "Als Standard setzen"
(star, `BankAccountsScreen`) and "Ausgleichen" (money bill, `OpenItemsScreen`). They stay in the ledger of `ClientToolbarIconTripwireTest`.
Inventing a table entry for a domain verb would break "one picture, one verb".

Domain icons that stay as strings in table action columns (`tableActionButton("fas ...")`, 17 calls, ledgered in the tripwire): key, link, user-lock,
medal, star, receipt, money, invoice, id card and similar.

=== Events, V1.9.47

The four event screens take `ADD` for "Veranstaltung anlegen", "Raum anlegen", "Schicht anlegen" and "Position anlegen" and `CANCEL` for "Abbrechen" of the
collapsed create forms. Without a standard icon, each for the reason given:

* *Navigation row of the events page* ("Räume", "Helfer-Schichten", "Catering", "Check-in"): navigation, not a verb.
* "Veröffentlichen" (publishing an event is a domain act; a check mark would claim "approve"), "Absagen" (deliberately not `CANCEL`: that picture means
  "close this form" and would invert the meaning of cancelling an event), "Warteliste nachrücken", "Aktivieren" (consent-and-activation family above),
  "Zusagen anzeigen" (opens a roster, not `VIEW` of an object).
* "Kopieren" / "Kopiert" (public URL of an event): `COPY` is in the table, but the button swaps its own text to "Kopiert" for two seconds, and
  `Button.text = ...` replaces the content including the icon. It stays a text button until `actionButton` can hold a label that changes
  without losing the icon; the accessible name "Kopieren" is unchanged.

=== Community, V1.9.48

Standard icons added: `ADD` ("Kontakt anlegen", "Mitglied anlegen", "Landesverband anlegen", "Als Landesvorstand eintragen"), `SEND` ("Projekt einreichen"),
`SAVE` ("Interaktion speichern", "Stammdaten speichern", "Status ändern", "Sterbedatum korrigieren", "Rolle ändern", "Mitgliedschaftsstufe speichern" and
"... zuweisen", "Beschreibung speichern"), `REMOVE` ("Mitgliedschaftsstufe entfernen": an assignment is released, the tier itself stays), `REVOKE` ("Einwilligung
widerrufen", "Zugang entziehen", "Jetzt entziehen"), `DELETE` ("Löschen nach Art. 17 DSGVO"), `APPROVE` ("Annehmen"), `UPLOAD` ("Wappen hochladen/ersetzen").
Without a standard icon, each for the reason given:

* "Like" / "Dislike": domain verbs of the crowdfunding vote, not generic approve/reject (the board decision uses `APPROVE`/`REJECT`).
* "Archivieren" / "Entarchivieren": a domain verb; the table has no archive entry and a trash can would read as deletion.
* "Verteilung berechnen": a domain verb (a calculation, not a save).
* "Landesvorstand verwalten", "Landesverband zuordnen", the candidate-status chips ("kein Login-Konto", "bereits Landesvorstand"), "Verbergen" /
  "Anzeigen" and "Mehr laden" (both lists): navigation or state, not a verb of the table.
* Pager "‹ Zurück" / "Weiter ›" of the member roster: the arrows are part of the label; the accessible name is unchanged. Moving the glyphs to
  `BACK`/`NEXT` icons is a follow-up.
* The six icon-only buttons in the member roster rows stay string-typed (`tableActionButton("fas ...")`, ledgered at 6): they are distinguished by
  their picture alone, so each needs its own distinct glyph. `receipt` (Beitragshistorie), `medal` (Ehrungen), `id-card` (Mitgliedsausweis), `image`
  (Foto entfernen), `comment-slash` (Kurzvorstellung entfernen) and `key` (Zugang zurücksetzen). `REMOVE` does not apply to destroying data (the
  "Token entfernen" precedent), `DELETE` in a member row would be read as "delete the member", and a password reset is not `UNDO`.

== Known limitations

* Buttons with extra constructor arguments (for example `className`) are not converted (`ClientVersionWatcher`, one ledgered call).
* The 17 domain icons above and the many domain verbs are intentionally left as they are.
* `fa-rotate` (password reset, re-index) still stands apart from `REFRESH` where the meaning is "reset", not "reload".
