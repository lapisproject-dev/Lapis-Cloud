= Flag icons: provenance

V1.9.121 adds the country and nationality selection lists, which show a small flag next to every country name.
The 250 flag files are copied byte for byte from the npm package `flag-icons` 7.5.0 (MIT, latest release on 2025-05-29, checked 2026-10-12).
They are checked in as own assets (no npm dependency, no `yarn.lock` change) and are served from the same origin only; nothing is ever fetched from a third party, and no emoji flags are used (Windows does not render them).

| Checksums | `MANIFEST.sha256` lists the SHA-256 of every shipped flag (`sha256sum`-style, relative to this directory); `FlagAssetsTest` checks it

Content rules (checked by `FlagAssetsTest`): no `<script`, no event handler attribute, no `<foreignObject`, no external reference, no entity declaration, no source-map comment, no embedded raster `<image`.
The flags are only ever used as `<img>` (never inline), always with an empty `alt` and `aria-hidden="true"`: the country name next to the flag is the accessible name.

These files are served immutable for a year. If the bytes ever change, rename the directory to `flag-icons-v8`
(`CountryFlag.DIR` in the client, `FLAG_ICONS_ASSET_DIR` in `ClientAssetRoutes.kt`, `lapis-client/build.gradle.kts`) and update `FlagAssetsTest`.
