= RNNoise assets: provenance

V1.9.114 adds the optional microphone noise suppression (RNNoise, run in the browser only).
The four shipped files are copied byte for byte from the npm package `@sapphi-red/web-noise-suppressor` 0.4.1 (MIT, published 2026-09-19, checked 2026-10-12).
They are checked in as own assets (no npm dependency, no `yarn.lock` change) and are served from the same origin only; nothing is ever fetched from a third party.

== Versioning rule

The directory is served `immutable` for one year (`Cache-Control: public, max-age=31536000, immutable`).
If the bytes of ANY file ever change, the directory MUST be renamed to `rnnoise-v2` (and the three places that name it: `NoiseSuppressionAssets.DIR` in `ConferenceNoiseSuppression.kt`, `RNNOISE_ASSET_DIR` in `ClientAssetRoutes.kt`, and `lapis-client/build.gradle.kts`), otherwise browsers keep the old bytes.
`RnnoiseAssetsTest` pins the sizes and SHA-256 values above.
