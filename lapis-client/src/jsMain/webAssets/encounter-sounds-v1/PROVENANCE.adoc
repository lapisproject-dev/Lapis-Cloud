== Versioning rule

The directory is served `immutable` for one year (`Cache-Control: public, max-age=31536000, immutable`).
If the bytes of either file ever change, the directory MUST be renamed to `encounter-sounds-v2` (and the three places that name it: the client constant in `EncounterSoundFetch.kt`, `ENCOUNTER_SOUNDS_ASSET_DIR` in `ClientAssetRoutes.kt`, and `lapis-client/build.gradle.kts`), otherwise browsers keep the old bytes.
`EncounterSoundAssetsTest` pins the sizes and SHA-256 values above.
